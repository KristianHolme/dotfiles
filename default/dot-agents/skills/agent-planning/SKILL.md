# Agent planning

## Interview until clear

- Do not ship ambiguous plans (“do X with approach A or B”). Pick one approach or ask until one is chosen.
- Interview until both of you share a detailed, complete understanding. The user may not know what they want yet — help them get there.
- Be liberal with clarifying questions. There should be no silent “optional” plan items: ask whether each optional piece should be included.
- Always ask whether to do testing/verification.

## When to plan vs implement

- Prefer a clear written plan when architecture, trade-offs, or multi-file scope are unclear.
- After the plan is agreed, implement only what was agreed — nothing extra (no unsolicited examples, tests, or drive-by refactors).
